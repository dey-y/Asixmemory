# ClassCalendar

### Propuesta del proyecto <a href="#propuesta-del-proyecto" id="propuesta-del-proyecto"></a>

La clase necesita un sitio único donde consultar las tareas que van saliendo, y cada alumno quiere poder llevar la cuenta de las suyas.

**Contexto.** El 14 de octubre de 2026, en clase, se eligió delegado y subdelegado. Entonces surgió la cuestión de cómo recordar las tareas, con un formato tipo calendario, a medida que los profesores las asignan.

**Propuesta del delegado.** Una mini pizarra en el aula donde cualquiera pueda consultar lo que hay para la semana.

**Propuesta de Dey.** Un bot para WhatsApp o Discord que:

* cada mañana muestre las actividades del día;
* por la tarde publique las novedades que se hayan añadido, para que la gente adelante tarea.

La hora de las novedades se pensó primero a las 20:00, porque el delegado debía recibir antes la información y luego publicarla en el grupo. Después Dey planteó adelantarla a las 17:00 para dar más margen.

Dey prefiere Discord a WhatsApp porque los canales ordenan la información y el bot no se mezcla con la conversación general del chat. También imaginó que los profesores pudieran gestionar las tareas ellos mismos en Discord, aunque lo ve poco probable.

**Alcance.** Una clase de 27 personas.
