# Introducción

En este módulo, se le presentan los tipos de servicio en la nube. Aprenderá cómo cada tipo de servicio en la nube determina la flexibilidad que tiene con la administración y configuración de recursos. Comprende cómo se aplica el modelo de responsabilidad compartida a cada tipo de servicio en la nube y explora varios casos de uso para cada tipo de servicio en la nube.

### Objetivos de aprendizaje <a href="#learning-objectives" id="learning-objectives"></a>

Después de completar este módulo, podrá:

* Describir la infraestructura como servicio (IaaS).
* Describir la plataforma como servicio (Paas).
* Describir el software como servicio (SaaS).
* Identificar los casos de uso adecuados para cada servicio en la nube (IaaS, PaaS, SaaS).
