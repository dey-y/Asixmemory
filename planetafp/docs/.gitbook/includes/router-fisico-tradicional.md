### Router físico tradicional

Se configura normalmente de forma individual.

El hardware y el software suelen estar unidos en el mismo equipo.

Los cambios pueden tardar más si hay muchos equipos.

Requiere comprar equipos para aumentar la capacidad.

La automatización suele ser más limitada.
{% endcolumn %}

{% column %}
### SDN

Se puede administrar desde un controlador central.

El control de la red se separa de los dispositivos físicos.

Las reglas pueden aplicarse a muchos dispositivos a la vez.

Permite modificar la red mediante software.

Facilita la automatización y la programación.
{% endcolumn %}
{% endcolumns %}
