# Descripción del software como servicio

Software como servicio (SaaS) es el modelo de servicio en la nube más completo desde el punto de vista del producto. Con SaaS, básicamente se alquila o se usa una aplicación totalmente desarrollada. El correo electrónico, el software financiero, las aplicaciones de mensajería y el software de conectividad son ejemplos comunes de una implementación de SaaS.

Aunque el modelo de SaaS puede ser el menos flexible, también es el más fácil de ponerse en marcha. Requiere la menor cantidad de conocimientos técnicos o experiencia para emplearlo plenamente.

### Enfoque de responsabilidad en SaaS <a href="#responsibility-focus-in-saas" id="responsibility-focus-in-saas"></a>

En SaaS, el proveedor de nube administra casi toda la pila de aplicaciones, incluida la infraestructura, la plataforma y el mantenimiento de aplicaciones. Administra principalmente los datos, la configuración de identidad y acceso y la posición de acceso del dispositivo. SaaS tiene la menor sobrecarga operativa para los clientes.

Por ejemplo, un equipo que usa una plataforma de colaboración SaaS puede centrarse en la incorporación de usuarios, los controles de acceso y la gobernanza de datos, mientras que el proveedor controla la aplicación de revisiones de infraestructura, las actualizaciones de aplicaciones y la disponibilidad.

### Escenarios <a href="#scenarios" id="scenarios"></a>

Entre los escenarios comunes de SaaS se incluyen:

* Correo electrónico y mensajería
* Aplicaciones de productividad.
* Seguimiento de finanzas y gastos
