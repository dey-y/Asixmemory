# Descripción de los tipos de servicio en la nube

En este módulo se tratan los distintos tipos de servicio en la nube y se comparten algunos de los casos de uso y las ventajas alineados con cada tipo de servicio.

### Objetivos de aprendizaje

Después de completar este módulo, podrá:

* Describir la infraestructura como servicio (IaaS).
* Describir plataforma como servicio (PaaS).
* Describir software como servicio (SaaS).
* Identifique los casos de uso adecuados para cada servicio en la nube (IaaS, PaaS, SaaS).

### Requisitos previos

* Conocimientos básicos sobre los términos y conceptos de TI
