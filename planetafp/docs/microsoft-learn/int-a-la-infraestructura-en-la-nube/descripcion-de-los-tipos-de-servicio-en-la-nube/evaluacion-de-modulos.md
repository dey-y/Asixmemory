# Evaluación de módulos

### Comprobación de conocimientos <a href="#quiz-title" id="quiz-title"></a>

1.¿Qué tipo de servicio en la nube es más adecuado para una migración mediante lift-and-shift de un centro de datos local a una implementación en la nube?

* [x] Infraestructura como servicio (IaaS)
* [ ] Plataforma como servicio (PaaS)
* [ ] Software como servicio (SaaS)

**Respuesta correcta:** Infraestructura como servicio (IaaS)

**Explicacion:** La migración lift-and-shift (reubicación directa) consiste en mover las aplicaciones y servidores virtuales tal como están desde tu centro de datos local a máquinas virtuales en la nube sin rediseñar el software. IaaS es el modelo perfecto para esto porque te proporciona directamente la infraestructura de cómputo y red equivalente.

2.¿En qué tipo de servicio en la nube se encuentra normalmente una solución de seguimiento de finanzas y gastos?

* [ ] Infraestructura como servicio (IaaS)
* [ ] Plataforma como servicio (PaaS)
* [x] Software como servicio (SaaS)

**Respuesta correcta:** Software como servicio (SaaS)

**Explicacion**Una aplicación de finanzas, contabilidad o gestión de gastos lista para usarse por los usuarios finales (como QuickBooks Online, SAP Concur o Microsoft Dynamics 365) es un producto de software completo alojado y gestionado por el proveedor, lo que se clasifica como SaaS.
