# Introducción a los aspectos básicos de Microsoft Azure

Microsoft Azure es una plataforma informática en la nube con un conjunto cada vez mayor de servicios que le ayudarán a crear soluciones que cumplan sus objetivos técnicos.

Los servicios de Azure admiten todo, desde simple a complejo. Puede hospedar servicios web simples para aplicaciones accesibles desde Internet, ejecutar equipos totalmente virtualizados para soluciones de software personalizadas o usar servicios basados en la nube, como almacenamiento remoto, hospedaje de bases de datos y administración centralizada de cuentas.

En esta serie, se tratan los aspectos básicos de la informática en la nube, se presentan algunos de los servicios principales proporcionados por Microsoft Azure y se obtienen más información sobre los servicios de gobernanza y cumplimiento que puede usar.

## ¿Qué es Aspectos básicos de Azure? <a href="#what-is-azure-fundamentals" id="what-is-azure-fundamentals"></a>

Aspectos básicos de Azure es una serie de tres rutas de aprendizaje que le familiarizan con Azure y sus muchos servicios y características y una ruta de aprendizaje que le ofrece la oportunidad de explorar Azure y crear soluciones para desafíos realistas de TI.

Independientemente de si está interesado en los servicios de proceso, redes o almacenamiento; aprender sobre los procedimientos recomendados de seguridad en la nube; o explorar las opciones de gobernanza y administración, piense en Aspectos básicos de Azure como guía seleccionada de Azure.

Aspectos básicos de Azure incluye contenido guiado y comprobaciones de conocimientos que refuerzan los conceptos clave.

La experiencia técnica de TI no es necesaria; sin embargo, tener conocimientos generales de TI le ayudará a sacar el máximo partido de su experiencia de aprendizaje.

### ¿Por qué debo tomar aspectos básicos de Azure? <a href="#why-should-i-take-azure-fundamentals" id="why-should-i-take-azure-fundamentals"></a>

Si acaba de empezar a trabajar con la nube o si ya tiene experiencia en la nube, Azure Fundamentals le proporciona todo lo que necesita para empezar.

Independientemente de sus objetivos, Aspectos básicos de Azure tiene algo para usted. Debe seguir este curso si:

* Tener interés general en Azure o en la informática en la nube
* Quiere obtener la certificación oficial de Microsoft (AZ-900)

La serie de rutas de aprendizaje aspectos básicos de Azure puede ayudarle a prepararse para el examen AZ-900: Aspectos básicos de Microsoft Azure. Este examen incluye tres áreas de dominio de conocimiento:

Este entrenamiento le ayuda a desarrollar una amplia comprensión de Azure.
