### Comprobación de conocimientos <a href="#quiz-title" id="quiz-title"></a>

1.¿Qué tipo de escalado implica agregar o quitar recursos (como máquinas virtuales o contenedores) para satisfacer la demanda?

* [x] Escalado vertical
* [ ] Escalado horizontal
* [ ] Escalado directo

**Respuesta correcta:** Escalado horizontal

Porque: El enunciado pregunta que tipo de escalado implica agregar o quitar recursos **(como maquinas virtuales o contenedores).**\
El escalado vertical consiste en aumentar o reducir recursos de una maquina, en este caso el enunciado menciona esa parte pero haciendo referencia a "como maquinas virtuales"

2.¿Qué se describe como la capacidad de un sistema de recuperarse de los errores y seguir funcionando?

* [ ] Confiabilidad
* [ ] Prediccion
* [x] Escalabilidad

**Respuesta correcta:** Confiabilidad

Porque:  La confiabilidad es la capacidad de un sistema para **recuperarse ante fallos y mantener su disponibilidad.** \
La escalabilidad es la capacidad de adaptarse al aumento o disminución de carga.

3.¿Qué práctica en la nube admite más directamente la sostenibilidad al reducir el uso innecesario de recursos?

* [x] Reducción automática de recursos cuando se reduce la demanda
* [ ] Despliegue de cada carga de trabajo como capacidad pico siempre activa
* [ ] Usar solo hardware local

**Respuesta correcta:** Reducción automática de recursos cuando se reduce la demanda
