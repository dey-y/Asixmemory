# M370T1A3-RJ45

¿Que tengo que hacer para "crimpar" cables UTP?\
Para crimpar un cable UTP, necesitas cortar la cubierta, ordenar los 8 hilos internos según el código de colores estándar, introducirlos en un conector RJ45 y presionarlos con una crimpadora

¿Qué es una grimpadora? ¿Cómo se utiliza?

Una crimpadora es una herramienta manual o automática diseñada para unir cables y conectores metálicos de forma permanente mediante la deformación por presión.

| Como se usa?                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 - Pelar el cable: Retira una pequeña porción del aislamiento exterior (aproximadamente unos 4 a 6 milímetros, según el terminal) para dejar los hilos de cobre al descubierto sin dañarlos.                                |
| 2 - Elegir la ranura correcta: Selecciona la muesca o matriz adecuada en la crimpadora según el grosor del cable (sección en mm²) o el código de color del terminal (por ejemplo, rojo, azul o amarillo)                     |
| 3 - Colocar el terminal: Inserta el terminal metálico en la abertura correspondiente de la herramienta.                                                                                                                      |
| 4 - Insertar el conductor: Introduce los hilos de cobre pelados dentro del terminal hasta el fondo, asegurándote de que no queden filamentos sueltos fuera                                                                   |
| 5 - Accionar la herramienta: Aprieta los mangos de la crimpadora con firmeza hasta que el mecanismo se libere o cierre por completo (muchas cuentan con un trinquete o carraca que asegura que se aplique la presión exacta) |
| 6 - Comprobar la unión: Tira suavemente del cable para verificar que el terminal ha quedado firmemente sujeto y no se desliza                                                                                                |
