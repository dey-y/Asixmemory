# ¿Qué son las redes?

## ¿Qué? ¿Por Qué? ¿Impacto?

### **¿Qué es una red?**

Una red es un conjunto de dispositivos conectados entre sí para compartir información, recursos y servicios. Estos dispositivos pueden ser ordenadores, móviles, impresoras, servidores o routers.

**Por ejemplo:**

* Un ordenador puede conectarse a Internet mediante un router.
* Varios ordenadores pueden compartir una misma impresora.
* Los trabajadores pueden compartir archivos en una empresa.

Las conexiones pueden realizarse mediante cables, fibra óptica o señales inalámbricas, como el Wi‑Fi. \
**Fuente:** [https://ed.team/blog/que-son-las-redes-y-como-funciona-internet](https://www.ibm.com/es-es/think/topics/networking)

### **¿Cuál es su importancia?**

**Explícame por qué se considera que las redes de ordenadores son el sistema nervioso de la sociedad actual usando un ejemplo real de interrupción de servicio a gran escala.**

Las redes de ordenadores son importantes porque conectan dispositivos y permiten compartir información, recursos y servicios rápidamente.

**Por ejemplo:**

* Los trabajadores pueden compartir archivos y comunicarse por videollamada.
* Un hospital puede consultar la información de sus pacientes desde diferentes ordenadores.

Por eso, las redes se comparan con el sistema nervioso de la sociedad, ya que transmiten información entre personas, dispositivos y empresas.

## ¿Qué contenidos tenemos que dominar?

### **¿Cuáles son los fundamentos físicos y lógicos a considerar?**

{% columns %}
{% column %}
#### Fundamentos físicos <a href="#fundamentos-fsicos" id="fundamentos-fsicos"></a>

Son los componentes necesarios para conectar los dispositivos y transportar la información.

**Por ejemplo:**

* Cables de red y fibra óptica.
* Antenas y redes Wi‑Fi.
* Ordenadores, móviles e impresoras.
* Switches, routers y puntos de acceso.
* Servidores que almacenan información o proporcionan servicios.
{% endcolumn %}

{% column %}
#### Fundamentos lógicos <a href="#fundamentos-lgicos" id="fundamentos-lgicos"></a>

Son las direcciones, configuraciones y reglas que indican cómo deben comunicarse los dispositivos.

**Por ejemplo:**

* El protocolo DNS transforma el nombre de una página web en una dirección IP.
* El protocolo DHCP asigna automáticamente una dirección IP.
* Los protocolos HTTP y HTTPS permiten visitar páginas web.
* Los protocolos Wi‑Fi y Ethernet permiten transmitir datos de forma inalámbrica o mediante cable.
{% endcolumn %}
{% endcolumns %}

En resumen, los fundamentos físicos son los cables y dispositivos, mientras que los fundamentos lógicos son las direcciones y reglas que permiten que la información llegue correctamente a su destino.\
**Fuente:** [https://ed.team/blog/que-son-las-redes-y-como-funciona-internet](https://ed.team/blog/que-son-las-redes-y-como-funciona-internet)

### **¿Qué dispositivos de red tenemos que aprender a configurar? ¿Qué son los protocolos? ¿Cuál es su uso?**

#### ¿Qué dispositivos de red tenemos que aprender a configurar? <a href="#qu-dispositivos-de-red-tenemos-que-aprender-a-conf" id="qu-dispositivos-de-red-tenemos-que-aprender-a-conf"></a>

**Los principales dispositivos son:**

* **Switch:** conecta ordenadores, impresoras y servidores dentro de una misma red.
* **Router:** conecta redes diferentes, como la red de una empresa con Internet.
* **Punto de acceso:** permite conectar dispositivos mediante Wi‑Fi.
* **Firewall:** controla el tráfico y bloquea conexiones no autorizadas.
* **Servidor:** proporciona servicios, como guardar archivos, gestionar usuarios o alojar páginas web.

#### ¿Qué son los protocolos? <a href="#qu-son-los-protocolos" id="qu-son-los-protocolos"></a>

Los protocolos son un conjunto de reglas que indican cómo deben comunicarse los dispositivos de una red. Es parecido a un idioma común: si todos siguen las mismas reglas, pueden entenderse.

#### ¿Cuál es su uso? <a href="#cul-es-su-uso" id="cul-es-su-uso"></a>

Los protocolos sirven para enviar, recibir y organizar la información correctamente. \
**Algunos ejemplos son:**

* **IP:** identifica el origen y el destino de los datos.
* **TCP:** comprueba que la información llegue correctamente.
* **DNS:** convierte el nombre de una página web en una dirección IP.
* **DHCP:** asigna automáticamente direcciones IP.
* **HTTP y HTTPS:** permiten acceder a páginas web.
* **Wi‑Fi y Ethernet:** permiten transmitir datos de forma inalámbrica o mediante cable.

## ¿El Futuro "Presente"?

### **¿Qué es la virtualización de Redes?**

**¿SDN?, ¿NFV?, Cloud (AWS, Azure), ¿Qué diferencia hay entre configurar un router físico tradicional y usar SDN? Resume los beneficios clave en entornos Cloud.**

La virtualización de redes consiste en crear redes y dispositivos de red mediante software, sin depender únicamente de equipos físicos.\
**Esto permite:**

* Crear redes rápidamente.
* Separar varias redes dentro del mismo hardware.
* Simular redes

**Fuente:** [https://www.nutanix.com/es/info/virtualization/network-virtualization#definition](https://www.nutanix.com/es/info/virtualization/network-virtualization#definition)

#### ¿Qué es SDN?

SDN significa Software-Defined Networking, o redes definidas por software.\
**SDN separa:**

* El **plano de control**, que decide por dónde deben circular los datos.
* El **plano de datos**, que se encarga de transportar esos datos.

SDN sirve para gestionar, controlar y programar una red de forma centralizada mediante software, separando las decisiones de tráfico del hardware físico

**Fuente:** [https://www.hpe.com/lamerica/es/what-is/software-defined-networking.html](https://www.hpe.com/lamerica/es/what-is/software-defined-networking.html)

#### ¿Qué es NFV? <a href="#qu-es-nfv" id="qu-es-nfv"></a>

NFV significa Network Functions Virtualization, o virtualización de funciones de red.\
Consiste en convertir funciones que antes realizaban equipos físicos específicos en programas que se ejecutan en servidores estándar.

**Fuente:** [https://www.hpe.com/lamerica/es/what-is/network-functions-virtualization.html](https://www.hpe.com/lamerica/es/what-is/network-functions-virtualization.html)

#### Cloud: AWS y Azure

La computación en la nube permite utilizar servidores, almacenamiento, redes y aplicaciones a través de Internet, sin tener que comprar y mantener todos los equipos físicamente.

AWS y Azure son dos de las principales plataformas cloud.

**Los principales beneficios son:**

* **Escalabilidad:** se pueden aumentar los recursos cuando crece la demanda.
* **Flexibilidad:** las redes se crean y modifican mediante software.
* **Rapidez:** se pueden desplegar servicios en minutos.
* **Disponibilidad:** se pueden repartir los servicios en varias zonas o regiones.
* **Automatización:** muchas tareas pueden realizarse mediante plantillas o scripts.
* **Menor inversión inicial:** no es necesario comprar todo el hardware desde el principio.

**Fuentes:** [https://aws.amazon.com/es/what-is-cloud-computing/](https://aws.amazon.com/es/what-is-cloud-computing/)

#### ¿Qué son los contenedores?

Los **contenedores** son entornos aislados que permiten ejecutar una aplicación con todo lo necesario para funcionar: código, librerías y configuraciones.

A diferencia de una máquina virtual, el contenedor no necesita un sistema operativo completo para cada aplicación. Por eso suele ser más ligero y rápido.

#### Router tradicional frente a SDN

{% columns %}
{% column %}
#### Router físico tradicional

Se configura normalmente de forma individual.

El hardware y el software suelen estar unidos en el mismo equipo.

Los cambios pueden tardar más si hay muchos equipos.

Requiere comprar equipos para aumentar la capacidad.

La automatización suele ser más limitada.
{% endcolumn %}

{% column %}
#### SDN

Se puede administrar desde un controlador central.

El control de la red se separa de los dispositivos físicos.

Las reglas pueden aplicarse a muchos dispositivos a la vez.

Permite modificar la red mediante software.

Facilita la automatización y la programación.
{% endcolumn %}
{% endcolumns %}

#### Ejemplo sencillo <a href="#ejemplo-sencillo" id="ejemplo-sencillo"></a>

En una red tradicional, para bloquear una página web en veinte routers tendríamos que configurar los equipos uno por uno.

En una red SDN, el administrador puede crear una regla en el controlador central y aplicarla automáticamente a toda la red.

#### Beneficios de SDN en la nube

SDN ofrece varios beneficios en los entornos cloud porque permite controlar la red mediante software desde una plataforma central.

* **Aislar departamentos, clientes o aplicaciones:** permite separar el tráfico de diferentes usuarios o servicios.
* **Modificar rutas y permisos rápidamente:** los administradores pueden cambiar quién tiene acceso a un servicio o por dónde circulan los datos sin configurar cada dispositivo manualmente.
* **Automatizar la creación de redes:** las redes pueden crearse mediante programas, plantillas o scripts.&#x20;
* **Controlar redes grandes desde una plataforma central:** el administrador puede supervisar y modificar muchos dispositivos desde un solo lugar, en vez de configurar cada router o switch.
* **Integrar la red con servidores, contenedores y aplicaciones:** SDN puede conectar automáticamente una aplicación con los servicios que necesita, como una base de datos o un servidor web.
* **Adaptar los recursos al número de usuarios o al tráfico:** si aumenta el número de usuarios, la red puede ampliar sus recursos. Cuando la actividad disminuye, puede reducirlos para ahorrar costes.

Por ejemplo, si un servidor empieza a recibir muchas más conexiones de lo normal, la IA puede detectarlo y avisar al administrador para que revise qué está ocurriendo.

### ¿Qué es AIOps? <a href="#qu-es-aiops" id="qu-es-aiops"></a>

AIOps significa inteligencia artificial aplicada a las operaciones informáticas. Consiste en utilizar la inteligencia artificial y el aprendizaje automático para vigilar redes, servidores y aplicaciones.

AIOps recoge información de diferentes dispositivos y aprende cuál es el comportamiento normal de la red. Después, compara ese comportamiento con lo que está ocurriendo en cada momento. Si encuentra algo diferente, genera una alerta.

**Fuente:** [https://www.redhat.com/es/topics/automation/observability-to-aiops-automation](https://www.redhat.com/es/topics/automation/observability-to-aiops-automation)\

#### ¿Cómo detecta problemas? <a href="#cmo-detecta-problemas" id="cmo-detecta-problemas"></a>

El sistema puede aprender, por ejemplo:

{% columns %}
{% column %}
* Cuánto tráfico recibe normalmente un servidor.
* Qué cantidad de errores suele haber
{% endcolumn %}

{% column %}
* Cuántos usuarios se conectan habitualmente.
* Cuál es la velocidad normal de la red.
{% endcolumn %}
{% endcolumns %}

Si de repente el tráfico aumenta mucho, la red se vuelve lenta o aparecen demasiados errores, AIOps puede detectar que existe una anomalía.\
Por ejemplo, si una página recibe normalmente 1.000 visitas por hora y de repente recibe 100.000 conexiones en pocos minutos, el sistema puede avisar de un posible problema o ataque DDoS.

#### ¿Cómo ayuda ante un ataque DDoS?

Un ataque DDoS intenta saturar un servidor enviándole muchas solicitudes al mismo tiempo. AIOps puede detectar señales como:

{% columns %}
{% column %}
* Un aumento repentino de conexiones.
* Muchas solicitudes parecidas.
{% endcolumn %}

{% column %}
* Tráfico procedente de miles de direcciones IP.
* Lentitud en la página o el servidor.
{% endcolumn %}
{% endcolumns %}

Cuando detecta estas señales, puede avisar al equipo de seguridad y, si está configurado para ello, limitar el tráfico, bloquear algunas conexiones o activar una protección contra ataques.
