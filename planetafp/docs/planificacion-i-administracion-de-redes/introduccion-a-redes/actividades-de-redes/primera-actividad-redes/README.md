# Primera actividad redes

### Introducción <a href="#introduccin" id="introduccin"></a>

En esta actividad se documenta una introducción al mundo de las redes informáticas: qué son, cómo funcionan (dispositivos, cables, fibra óptica, Wi‑Fi) y por qué son importantes. Se recogen también las principales salidas profesionales del sector, comparando el perfil de técnico en sistemas y redes (ASIX) con el de analista de ciberseguridad/SecOps.

Se documentan además los fundamentos físicos y lógicos de las redes, los dispositivos clave a configurar (switch, router, punto de acceso, firewall, servidor) y los protocolos de comunicación más relevantes (IP, DNS, DHCP, TCP, HTTP/HTTPS, Wi‑Fi, Ethernet).

Por último, se incluye la virtualización de redes (SDN, NFV, cloud, contenedores) y el papel de la inteligencia artificial mediante AIOps para detectar anomalías de tráfico y prevenir ataques DDoS.
